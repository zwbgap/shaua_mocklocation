# 迁境 (MockLocation) 优化路线图

> 本文档记录后续版本的优化方向与功能规划，按优先级排序。

---

## 一、UI 美化优化

### 高优先级

| 编号 | 优化项 | 说明 | 优先级 |
|------|--------|------|--------|
| UI-01 | 启动页（Splash Screen） | 添加应用图标 + 名称 + 版本号的启动页，2 秒后自动跳转，避免白屏闪烁；使用 Android 12+ SplashScreen API 兼容新旧系统 | 高 |
| UI-02 | 空状态界面 | 收藏列表为空、搜索无结果时显示插图 + 引导文案（如"还没有收藏，长按地图添加收藏吧"） | 高 |
| UI-03 | 加载状态 | 搜索时显示加载动画（骨架屏或 ProgressBar）；地图加载时显示加载提示 | 高 |
| UI-04 | 弹窗圆角升级 | Material 3 推荐对话框圆角为 28dp，调整 `dialogCornerRadius` 以更符合 M3 设计规范 | 高 |
| UI-05 | 地图控制按钮组 | 将分散的 ImageButton 改为垂直方向的圆形按钮组，带阴影和选中态视觉反馈（涟漪 + 缩放） | 高 |
| UI-06 | 收藏列表卡片化 | 列表项增加卡片背景 + 圆角 + 阴影；收藏时间显示更友好（"3 天前"而非时间戳） | 高 |

### 中优先级

| 编号 | 优化项 | 说明 | 优先级 |
|------|--------|------|--------|
| UI-07 | 页面过渡动画 | Activity/Fragment 切换添加过渡动画（淡入淡出、滑动） | 中 |
| UI-08 | 传送按钮动效 | FAB 传送按钮添加脉冲动画，运行时状态有视觉区分 | 中 |
| UI-09 | 主题切换预览 | 主题选择时实时预览配色效果，无需重启应用 | 中 |
| UI-10 | 沉浸式地图 | 地图页全屏沉浸模式，状态栏半透明覆盖 | 中 |

## 二、功能体验优化

### 高优先级

| 编号 | 功能项 | 说明 | 优先级 |
|------|--------|------|--------|
| FX-01 | 新手引导 | 首次启动高亮提示"长按地图查看地点详情"、引导设置模拟位置应用，通过 SharedPreferences 标记只显示一次 | 高 |
| FX-02 | 搜索历史下拉 | 搜索框下拉显示最近搜索历史，支持单条快速删除 | 高 |
| FX-03 | 收藏搜索 | 收藏列表顶部增加搜索框，支持按名称/地址过滤 | 高 |

### 中优先级

| 编号 | 功能项 | 说明 | 优先级 |
|------|--------|------|--------|
| FX-04 | 收藏分组/标签 | 收藏位置支持分组管理（如"家"、"公司"、"旅行"） | 中 |
| FX-05 | 收藏导入导出 | 支持 JSON 格式批量导入导出收藏，换机一键恢复，也可分享给他人 | 中 |
| FX-06 | 桌面快捷方式 | 长按应用图标弹出常用收藏位置，点击直接传送，无需打开应用 | 中 |
| FX-07 | 路线模拟 | 在地图上绘制路线，按设定速度（步行/骑车/驾车）沿路线移动，模拟真实运动轨迹 | 中 |
| FX-08 | 定时切换位置 | 按计划自动切换模拟位置（如工作日 9:00-18:00 模拟在公司），到时间自动执行 | 中 |
| FX-09 | 定位精度模拟 | 可配置模拟定位的精度范围（如 5m~50m），让模拟更逼真，避免被检测为固定精度 | 中 |
| FX-10 | WiFi/基站模拟 | 在 GPS+NETWORK 基础上，增加 WiFi 列表和基站信息模拟，进一步降低被检测概率 | 中 |

### 低优先级

| 编号 | 功能项 | 说明 | 优先级 |
|------|--------|------|--------|
| FX-11 | 快捷悬浮窗 | 屏幕边缘一个小按钮，快速打开收藏列表切换位置（轻量级，非摇杆） | 低 |
| FX-12 | 搜索历史热力图 | 在地图上展示常搜索/常去的位置，可视化使用习惯 | 低 |
| FX-13 | 海拔/速度曲线 | 模拟运行时显示海拔和速度的实时曲线图，增加专业感 | 低 |

## 三、工程质量与性能

| 编号 | 优化项 | 说明 | 优先级 |
|------|--------|------|--------|
| QS-01 | 坐标转换单元测试 | 为 `MapUtils` 的 BD09↔GCJ02↔WGS84 转换编写单元测试，确保精度 | 中 |
| QS-02 | 错误提示优化 | 网络错误、定位失败等场景给出友好的 Snackbar 提示 | 中 |
| QS-03 | 深色模式完整适配 | 所有页面深色模式最终验收，确保对比度符合 WCAG 标准（文字与背景对比度 ≥ 4.5:1） | 中 |
| QS-04 | 国际化 | 补充 `values-en/strings.xml`，支持中英文切换 | 低 |
| QS-05 | 地图内存管理 | 优化百度地图资源回收，避免长时间使用后内存增长 | 低 |
